# 准讯周报 · 视频样片

把周报内容自动做成带配音、字幕、动画图表的视频。三个样片代表三种方向：

| 样片 | 画幅 | 时长 | 内容 | 适合 |
|---|---|---|---|---|
| `out/a-weekly.mp4` | 竖屏 9:16 | 约 1 分 43 秒 | 本周速览：主线、三家公司收入涨现金跌、四个关键数字、三个判断、下周看点 | 抖音 / 视频号 / 小红书，每周固定一条 |
| `out/b-robot.mp4` | 竖屏 9:16 · 深色 | 约 1 分 22 秒 | 单条数据解说：机器人「91% → 50%」的连乘算术，曲线逐步画出 | 单条爆点新闻，拆成短视频 |
| `out/c-anthropic.mp4` | 横屏 16:9 | 约 2 分 56 秒 | 头条深度：Anthropic 账本，按网站结构走「发生了什么 → 核心判断 → 为什么 → 反方 → 预测台账 → 对你」 | B 站 / 视频号横屏 / 官网嵌入 |

配音是离线合成的（Kokoro 中文模型：A、B 女声，C 男声），背景音是程序合成的占位音乐。
正式发布前建议换成真人配音或商用 TTS，并换一首有授权的配乐。

## 怎么改、怎么重新生成

每个样片一个目录，只有两个文件需要改：

- `script.json`：旁白脚本。按 beat（段落）分组，每句有 `say`（念出来的文字，数字建议写成汉字）和 `cap`（屏幕字幕）。
  画面节奏完全跟着配音走：改了文案，时间轴自动重排。
- `scene.html`：画面。每个 `<section class="scene" data-beat="…">` 是一个场景；元素上写
  `data-at="three.2"` 就表示「在 three 这段的第 2 句开始时出场」，`data-count` 做数字滚动，`data-bar` 做条形图生长。
  直接用浏览器打开 `scene.html` 可以实时预览（空格暂停，左右方向键快进快退，需先跑过一次 `tts.py`）。

```bash
./build.sh                 # 生成全部三个样片
./build.sh b-robot         # 只生成一个
```

依赖：`python3`（`pip install sherpa-onnx numpy scipy soundfile`）、`node` + `playwright`、`ffmpeg`。
首次运行会自动下载 Noto 中文字体和语音模型到 `.cache/`（约 470 MB，不进仓库）。

## 工作原理

1. `lib/tts.py`：逐句合成语音，裁掉首尾静音，按句子时长排出时间轴 `build/timeline.json`。
2. `lib/music.py`：合成背景音，按旁白自动压低音量，混成 `build/mix.wav`。
3. `lib/render.mjs`：用无头浏览器逐帧调用 `seek(t)` 截图，交给 ffmpeg 编码，再合上音轨、做响度标准化（-16 LUFS）。
   画面是时间的纯函数，所以每次渲染结果完全一致。
4. `lib/check_voice.py`（可选）：用语音识别回听每句旁白，找出读错的多音字、英文名和数字。
