## 目前没有配音

样片是「字幕 + 配乐」版本（短视频里很多人静音看，字幕本身就是正文）。配音轨道留好了接口，可选方案：

1. **离线开源模型**（FastSpeech2 中文女声，PyPI 上的 zhtts 包）——这次环境的自动权限拦下了运行第三方模型代码这一步，需要你放行；
2. **微软 Edge 在线语音**（edge-tts，晓晓/云希等音色，效果最好）——需要允许访问 `speech.platform.bing.com`；
3. **剪映等工具里配音**，或真人录音，把音频交给我按句对齐画面。

## 自己渲染

需要 Node 20+、Playwright（Chromium）、ffmpeg、Python 3 + numpy/scipy，以及 Noto Sans/Serif CJK SC 字体。

```bash
# 1. 逐帧渲染画面（同时导出音效提示点 *.cues.json）
node engine/render.js samples/a-editorial /tmp/a.mp4
# 2. 合成配乐与音效
python engine/score.py /tmp/a.mp4.cues.json /tmp/a.wav
# 3. 合并、统一响度
ffmpeg -i /tmp/a.mp4 -i /tmp/a.wav -map 0:v -map 1:a -c:v libx264 -crf 24 -preset slow \
  -af loudnorm=I=-15:TP=-1.5 -c:a aac -b:a 192k -shortest out/A.mp4
```

在浏览器里直接打开 `samples/*/index.html` 可以无声预览（空格暂停，←/→ 跳一秒）。

## 文件

- `engine/engine.js` 时间线、逐字显影、数字滚动、胶片颗粒
- `engine/render.js` 逐帧截图并编码
- `engine/score.py` 三套配乐（钢琴弦乐 / 极简电子 / 新闻快讯）和二十来种音效
- `samples/` 三条样片的画面源文件
- `out/` 成片
